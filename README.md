## Seeding Instructions

To sync data across the team, follow these detailed steps:

1. **Ensure Database Connection**: Make sure that your environment is set up with the correct database connection strings in your `.env` file.

2. **Install Required Packages**: Run the following command to install the necessary packages:
   ```bash
   npm install
   ```

3. **Run Seeds**: Use the following command to run the seed files:
   ```bash
   npm run seed
   ```

4. **Confirm Data Sync**: Verify that the data has been seeded correctly by checking the respective tables in your database.

5. **Share Environment Variables**: If you have any new environment variables added, ensure to share them with the team.

6. **Check for Errors**: Look for any error messages in the console and debug as necessary. If you encounter issues, consult the documentation or reach out to the team.

By following these instructions, all developers should be able to effectively sync data and maintain consistency across development environments.

Feel free to reach out if you have any questions!
